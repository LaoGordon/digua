# 基于 BPU 的四足机器狗自主消防巡逻系统

> RDK S100P（128 TOPS BPU, Nash 架构） · Lite3 四足机器人 · ROS2 Humble · FAST-LIVO2 SLAM · Nav2

本项目在一台 RDK S100P 边缘计算板上，构建了一套完整的四足机器狗自主消防巡逻系统：**从 SLAM 定位、BPU 神经全局路径规划、火焰检测，到俯仰瞄准、喷淋灭火**。核心创新是用 BPU 加速的神经网络势场规划器（NeuralPathPlanner）替代 Nav2 传统的 NavfnPlanner，把规划算力从已满载的 CPU 卸载到 BPU。

## 三、核心创新：BPU 神经路径规划器

### 传统方案的问题

NavfnPlanner 用 Dijkstra 在全局代价图上逐格广播代价波（O(N log N)）。在室内大地图（959×1120，百万格）上单次规划可达 **>20 秒**，且全程吃满一个 CPU 核。而 RDK 板子上 FAST-LIVO2 SLAM 已占 40-60% CPU、Nav2 占 25%，CPU 已满载。

### 本方案：学习型势场规划 + BPU 卸载

```
传统:  costmap → Dijkstra全图扩展(CPU, 百万格, >20s) → 路径
本方案: costmap → [BPU CNN一次前向] → 势场 → gradientWalk提取路径(CPU, ~480节点)
                 (势场计算卸到BPU)      (轻量搜索留在CPU)
```

- **CNN 学 Dijkstra 的 cost-to-go 势场**：一次前向传播预测整张势场图
- **gradientWalk 提取路径**：沿势场下降的优先队列搜索，扩展节点数仅 ~480（A* 的 1/5）
- **BPU 承担重计算**：CNN 势场推理搬到 128 TOPS BPU，CPU 只做轻量搜索

### 真机验证（684 次规划，2026-07-08）

| 指标 | 结果 |
|------|------|
| 成功率 | **100%（684/684）** |
| 不穿墙率 | **100%** |
| 延迟（均值） | 52.0ms |
| 延迟（中位数） | 48.4ms |
| P90 / P99 | 76.6ms / 103.5ms |
| 搜索方法分布 | 100% gradientWalk |
